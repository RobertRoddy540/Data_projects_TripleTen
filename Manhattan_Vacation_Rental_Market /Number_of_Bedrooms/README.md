## 1. Which neighborhoods and property sizes i.e. number of bedrooms are most attractive for vacation rentals?

- To find the most attractive properties based on bedroom count I analyzed the data using pivot tables. 
- I looked into which neighborhoods were most attractive for vacation rentals, as well as the bedroom count that was most popular in each of those neighborhoods.  
- I also checked to confirm the most popular property size in each neighborhood to see if there were different bedroom counts more popular in certain neighborhoods.

- Using the length of time each listing was rented out I was able to assess the listings attractiveness. 

- Reviews are a great way to measure a listings attractiveness as they can help us gauge how often the listing is rented out.

- The analysis shows that out of the top 10 Neighborhoods for listings, Lower East Side, Hells Kitchen, and Harlom were by far the most popular.
